# Тестовое Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки и получает тему и черновик. Он сам решает, какой ответ отправить клиенту.

## Запуск

Нужен Node.js 20 или новее. Имитатор модели работает локально. Установка пакетов и ключи API не требуются. Запустите сервер из каталога проекта.

```sh
node server.mjs
```

Откройте [страницу заявок](http://127.0.0.1:3000). Порт можно задать через переменную `PORT`. Для остановки нажмите Ctrl+C.

## Тесты

Из того же каталога запустите встроенный тестовый раннер Node.js.

```sh
node --test
```

Тесты API проверяют HTTP-коды и JSON для обычных заявок, ошибок ввода и всех пяти сценариев сбоя имитатора. Тесты формы выполняют скрипт страницы и управляют порядком ответов, чтобы воспроизвести опоздавший результат и опоздавшую ошибку. Запускать сервер отдельно для тестов не требуется.

## Контракт API

`POST /api/triage` принимает JSON вида `{"text":"Когда будет доставка?"}`.

| Условие | HTTP | Тело ответа |
| --- | --- | --- |
| Нечитаемый JSON, отсутствующий или нестроковый `text`, пустой текст после `trim()` | 400 | `{"status":"invalid_input"}` |
| Имитатор вернул разрешённую тему и непустой черновик | 200 | `{"status":"ready","topic":"delivery","draft":"Спасибо за обращение. Уточним детали заявки."}` (пример) |
| Прошло 300 мс, имитатор выбросил исключение или вернул неподходящие данные | 200 | `{"status":"manual_review","topic":null,"draft":null}` |

Сервер проверяет ввод до обращения к имитатору. Из его ответа сервер берёт только тему (`delivery`, `pricing` или `other`) и строку черновика с непробельным текстом.

## Проверка в браузере

1. Введите «Когда будет доставка?» и нажмите «Разобрать заявку». На странице появятся тема доставки и черновик ответа.
2. Допишите к заявке `[timeout]` и отправьте её снова. Прежние тема и черновик сразу исчезнут. После таймаута появится предложение разобрать заявку вручную. Введённый текст останется в поле.
3. Повторите с метками `[error]`, `[bad-json]`, `[bad-topic]` или `[empty-draft]`, чтобы увидеть то же состояние. При отправке одних пробелов форма предложит ввести текст.

Пользу для менеджера можно оценить по времени от получения заявки до корректного решения и по числу случаев, когда в ответ клиенту попал черновик от предыдущей заявки.
